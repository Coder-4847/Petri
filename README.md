# Petri

A browser-based evolution sandbox. Start with bacteria in every biome and watch food chains, speciation and extinctions
emerge from simple rules — all the way to civilisation and several possible futures. You are a god-like observer.

```
npm install
npm run dev      # develop
npm run build    # production build (static, relative base — works on GitHub Pages)
```

See `ARCHITECTURE.md` for how it works and `PROGRESS.md` for the current state.
